# MVP · Design System

## Resultado mínimo
Construir una interfaz DesarrollAMO coherente usando primitivas reutilizables, accesibles y versionadas sobre Branding.

## Aceptación
- sincroniza tokens desde una versión fija de Branding;
- tema light/dark;
- foco visible y reduced-motion;
- layout, botones, cards, badges, inputs y tipografía;
- footer corporativo + atribución de clientes separados;
- specimen visual;
- `npm run check` reproduce build/validación;
- ningún producto específico se convierte en dependencia del sistema base.

## Fuera del MVP
- lógica de negocio;
- componentes sólo para llenar catálogo;
- redefinir marca manualmente.
